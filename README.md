# حروفي المرحة 🌈

تطبيق Android تعليمي تفاعلي للأطفال لتعلّم الحروف العربية عبر الاستكشاف والألعاب والتلوين والنطق الصوتي.

## التقنية
- React Native + Expo SDK 54
- واجهة عربية RTL
- تحويل النص إلى كلام عبر `expo-speech` (يعتمد على الأصوات العربية المثبتة في الجهاز)

## تشغيل المشروع
```bash
npm install
npx expo start
```
ثم افتح التطبيق باستخدام Expo Go المتوافق أو شغّله على محاكي Android.

## محتويات النسخة الأولية
- الحروف العربية الـ28 مع كلمة وصورة تعبيرية لكل حرف
- صفحة الحرف مع نطق الاسم والكلمة
- نشاط تلوين باختيار الألوان
- لعبة استمع واختر الحرف الصحيح
- عدّاد للنجوم والحروف التي استكشفها الطفل

## بناء Android
يمكن إعداد EAS Build بعد تثبيت المشروع والتحقق من توافق الاعتماديات:
```bash
npx expo install --check
npx expo run:android
```
